Usability Testing Report
Food Delivery Mobile App Prototype
1. Introduction

This project focuses on conducting usability testing for a Food Delivery Mobile App Prototype.

The purpose of usability testing is to:

evaluate user experience
identify usability problems
collect user feedback
improve application design

The testing was conducted on an interactive prototype developed using:

HTML
CSS
JavaScript

The prototype included:

Login Screen
Food Selection Screen
Cart Screen
Order Placement Flow


2. Objective of Usability Testing

The main objectives were:

Test whether users can easily navigate the app
Identify confusing interface elements
Measure ease of use
Gather feedback for design improvements
3. Features Tested

The following features were tested:

Feature	Purpose
Login System	User authentication flow
Food Cards	Food browsing experience
Add To Cart	Shopping interaction
Navigation Flow	Screen transitions
Order Placement	Checkout process


4. Usability Test Plan
Test Method

Moderated usability testing was conducted.

The tester observed users while they interacted with the prototype.

5. Test Environment
Item	Details
Device	Laptop / Mobile View
Browser	Chrome
Internet	Required for images
Duration	10–15 minutes per user

7. Test Scenarios

Users were asked to complete the following tasks.

Scenario 1 — Login
Task

User should:

enter email
enter password
click login
Expected Result

User navigates to Home Screen successfully.

Scenario 2 — Browse Food
Task

User should:

view food items
identify prices
explore cards
Expected Result

User understands available food options.

Scenario 3 — Add Food to Cart
Task

User should:

click Add To Cart button
Expected Result

Selected item appears in cart.

Scenario 4 — Place Order
Task

User should:

open cart
place order
Expected Result

Success message appears.

10. Problems Identified
Problem	Impact
No Back Navigation	Medium
No Quantity Selector	Medium
Cart lacks total amount	Medium
Limited food items	Low
11. Analysis of Results

The usability testing showed that:

users completed tasks successfully
navigation was mostly easy
interface was beginner-friendly

However:

users expected more shopping features
cart functionality needs improvement
navigation can be enhanced
